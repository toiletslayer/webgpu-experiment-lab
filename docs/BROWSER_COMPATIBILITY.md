# Browser Compatibility Matrix

| Browser | WebGPU status | Notes |
| --- | --- | --- |
| Chrome desktop | Expected on supported hardware | Primary initial WebGPU target. |
| Edge desktop | Expected on supported hardware | Chromium behavior should be close to Chrome. |
| Firefox desktop | Experimental/configuration dependent | Must be tested by release and platform. |
| Safari desktop | Platform and version dependent | Important for Apple Silicon. |
| Android Chrome | Device dependent | Thermal and background throttling likely. |
| iOS Safari | Device and OS dependent | Long-running compute behavior requires direct testing. |

This matrix is qualitative until measured on real devices.
