## SPHlib-derived Whirlpool reference material

CapStash Core's pinned `src/crypto/whirlpool/whirlpool.c` is an SPHlib-derived
plain WHIRLPOOL implementation. This project independently implements the
algorithm in JavaScript and WGSL, but its committed lookup tables and round
constants in `src/cpu/whirlpool-tables.js` were transcribed/generated from the
public `plain_T0` and `plain_RC` reference values used by that source. The same
project table data is converted into WGSL source at runtime; the upstream C
implementation itself is not copied into this repository.
