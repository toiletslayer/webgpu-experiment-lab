        Browser Limitations

        Hashes are computed by the JavaScript CPU reference implementation on the browser main thread.

        • `webgpu-plumbing-only` executes a temporary fake shader on the GPU to prove buffer layout, nonce mapping, dispatch, and readback.
        • `webgpu-plumbing-only` is not CapStash hashing, and CPU-reference mismatches are expected in that mode.
        • `webgpu-whirlpool-minimal` is correctness-only and supports tiny nonce counts while the real WGSL Whirlpool path is audited.
        • WGSL/Core results are selected-subset results unless the Core panel explicitly says `WGSL/Core verification: Full 294-vector pass`.
        • Full 294-vector verification is manual only and remains correctness-only, not optimized.
        • `webgpu-synthetic-nonce-benchmark` is a controlled synthetic local benchmark mode with an automatic correctness gate and CPU spot checks.
        • `webgpu-synthetic-profiling` profiles browser-observed host phases for the verified synthetic path and does not expose shader-internal GPU counters.
        • Current verified shader uses @workgroup_size(1); batch size 512 means 512 one-invocation workgroups.
        • Variant B profiling records logical dispatch count separately from physical queue submissions, queue waits, and combined readbacks.
        • The no-readback profiling probe is not a valid hash benchmark because output correctness is not established by that run alone.
        • Synthetic benchmark results are not target comparisons, not pool mining, not live network submission, and not profitability evidence.
        • Pipeline creation currently dominates timing for the observed minimal Whirlpool run.
        • Do not treat any WebGPU mode as a production miner.
        • Browsers do not expose reliable GPU temperature, power, clock, or fan telemetry to pages.
        • WebGPU adapter names may be redacted by privacy settings or browser policy.
        • Values shown here are Browser WebGPU Performance, not native CUDA, OpenCL, Vulkan, or CPU mining performance.
